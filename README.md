# Chatbot with Analytics

A simple Python and Streamlit project that combines a chatbot with data visualization.

## Features

- Chatbot using spaCy
- Optional OpenAI-powered responses
- Matplotlib line chart
- Seaborn scatter plot
- Plotly interactive bar chart
- Simple Streamlit interface
- Sample data for analytics visualization

## Technologies Used

- Python
- Streamlit
- spaCy
- OpenAI API
- Pandas
- Matplotlib
- Seaborn
- Plotly
